# Original-trigger ambiguity sensitivity

Root and independent design reviewer identified a distinction before final interpretation: counting a simultaneous original SL/TP hit as a stop is conservative for the hypothetical original trade, but it may create a profitable new fade entry. It is not necessarily conservative for the fade strategy.

Keep the preregistered SL-first primary unchanged. Flag every ambiguous original trigger. Separately report the fixed sensitivity that excludes such triggers; it cannot replace a failed primary or become a new winning variant. The new fade position's own ambiguous exit remains stop-first. No threshold, original first-exit rule or parameter changes.
