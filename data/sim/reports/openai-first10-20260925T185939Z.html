Every decision used a fresh subagent with no inherited conversation, medium reasoning, the original saved text and chart, and no feedback. The tool-call audit confirmed only the assigned stimulus files were accessed. Isolation was instruction-based and audited, not a hard filesystem or tool sandbox. Seven Terra attempts across four cases queried the computer app inventory; those attempts were excluded before scoring, preserved in the run folder, and repeated with fresh contexts. A fixed, single read-only tool call was introduced after verbal restrictions alone failed. One Astra attempt failed to load the numeric prompt due to a mistyped file path and was also excluded and repeated. Eight excluded attempts are retained separately. The wrapper instructions therefore changed during collection; saved user messages document each version. The original market prompt, chart and trade contract were preserved. All eligible attempts were audited.

The saved input text hashes match the Claude records. Chart bytes were fingerprinted for this run; the original Claude logs do not carry image hashes. Codex and Claude Code have different harnesses, so this comparison does not isolate model weights alone. No historical Claude record was rewritten.

Evaluation: unchanged existing one-minute first-passage engine, 72-hour timeout, 20 basis points round-trip costs. The prompt does not state the timeout. Excursions include the full exit bar. Per-trade averages are not portfolio returns. Ten windows are exploratory.
